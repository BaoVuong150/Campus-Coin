# Team deliverables (not stored in git)

Put these files here before running `node scripts/package-submission.mjs "<FILE_NAME>"`.
They are added to the root of the ZIP. Everything else in this folder is ignored by git.

| File | Rule checked by the script |
| --- | --- |
| Demo video | ends with `.mp4` |
| `ReadMe.doc` (or `ReadMe.docx`) | name is exactly ReadMe |
| Project report (`.docx` / `.pdf`) | name contains `report` or `bao cao`, e.g. `CampusCoin_Project_Report.pdf` |
